DDS Evrika Plugin 1.3

English | Русский

English

Import and export DirectDraw Surface (.dds) textures: BC1–BC7 compression, sRGB or linear color space, mipmaps for any texture size. Works in Krita 5 and Krita 6.

Commands

All commands are in Tools > Scripts.

Import DDSOpen a DDS file as a new document.
Import DDS as...Choose the intermediate format (PNG, TIFF, BMP, JPEG, TGA) first.
Export DDSSave the current document with the saved export settings.
Export DDS as...Choose export settings for this file; Remember these settings makes them default.
DDS Evrika SettingsDefault export options, encoder, paths to tools, language.

Export options

CompressionBC1/DXT1, BC2/DXT3, BC3/DXT5, BC4, BC5, BC7 or uncompressed RGBA8. BC2–BC7 need Cuttlefish.
Color spacesRGB for color textures: *_SRGB format, mipmaps averaged in linear light.
Linear for normal maps, masks and other data: *_UNORM format, values written unchanged.
MipmapsFull chain down to 1×1, no mipmaps, or 1–12 extra levels. Any image size works.
Mipmap filterResampling filter for mip levels. Cuttlefish uses the closest of box, linear, cubic, b-spline, catmull-rom.
QualityFast, Normal or Best. Best is slow for BC7.

Recommended: color with alpha → BC7 sRGB; normal map → BC5 linear; single channel mask → BC4 linear.

External tools

  • Cuttlefish writes all formats and the sRGB flag. Included in the release archives for Windows, Linux and macOS.
  • ImageMagick opens DDS files and can export DXT1, DXT5 and uncompressed. Included in the Windows archive; on Linux install it with the package manager (apt install imagemagick), on macOS with brew install imagemagick.

The settings dialog shows which tools were found and lets you set their paths manually.

Troubleshooting

  • ImageMagick was not found – install it or set the path to magick in DDS Evrika Settings.
  • ImageMagick cannot write BC7/BC2/BC4/BC5 – use Cuttlefish (encoder: Automatic) or pick DXT1/DXT5.
  • macOS blocks cuttlefish – run xattr -dr com.apple.quarantine ~/Library/Application\ Support/krita/pykrita/dds_evrika_plugin/resources.

More details: github.com/Sepera-okeq/DDS-Evrika-Plugin

Русский

Импорт и экспорт текстур DirectDraw Surface (.dds): сжатие BC1–BC7, цветовое пространство sRGB или linear, mipmap для текстур любого размера. Работает в Krita 5 и Krita 6.

Команды

Все команды находятся в Инструменты > Сценарии.

Импортировать DDSОткрыть DDS как новый документ.
Импортировать DDS как...Сначала выбрать промежуточный формат (PNG, TIFF, BMP, JPEG, TGA).
Экспортировать DDSСохранить текущий документ с сохранёнными настройками экспорта.
Экспортировать DDS как...Выбрать настройки для этого файла; Запомнить эти настройки делает их настройками по умолчанию.
Настройки DDS EvrikaПараметры экспорта по умолчанию, кодировщик, пути к программам, язык.

Параметры экспорта

Формат сжатияBC1/DXT1, BC2/DXT3, BC3/DXT5, BC4, BC5, BC7 или без сжатия RGBA8. BC2–BC7 требуют Cuttlefish.
Цветовое пространствоsRGB для цветных текстур: формат *_SRGB, mipmap усредняются в линейном свете.
Linear для нормалей, масок и других данных: формат *_UNORM, значения записываются без изменений.
Mipmap-уровниПолная цепочка до 1×1, без mipmap или 1–12 дополнительных уровней. Подходит любой размер.
Фильтр mipmapФильтр уменьшения для уровней. Cuttlefish берёт ближайший из box, linear, cubic, b-spline, catmull-rom.
КачествоБыстро, Нормально или Максимум. Максимум для BC7 работает медленно.

Рекомендации: цвет с альфой → BC7 sRGB; карта нормалей → BC5 linear; одноканальная маска → BC4 linear.

Внешние программы

  • Cuttlefish записывает все форматы и флаг sRGB. Входит в архивы релиза для Windows, Linux и macOS.
  • ImageMagick открывает DDS и умеет экспортировать DXT1, DXT5 и без сжатия. Входит в архив для Windows; на Linux установите его пакетным менеджером (apt install imagemagick), на macOS – brew install imagemagick.

В окне настроек видно, какие программы найдены, и можно указать пути вручную.

Решение проблем

  • ImageMagick не найден – установите его или укажите путь к magick в настройках DDS Evrika.
  • ImageMagick не умеет записывать BC7/BC2/BC4/BC5 – используйте Cuttlefish (кодировщик: Автоматически) или выберите DXT1/DXT5.
  • macOS блокирует cuttlefish – выполните xattr -dr com.apple.quarantine ~/Library/Application\ Support/krita/pykrita/dds_evrika_plugin/resources.
